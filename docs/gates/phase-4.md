## Local storage and limits

The runtime lives under selected shared storage and its bootstrap defaults to `.local-cache/shared-storage` in this repository. Project workflow input/output/user/temp/DB are bound to the active project; models/cache are shared. The engine does not download model packs. The current broker still lacks restart recovery and guaranteed remote cancellation; live provider API smoke and local media uploads remain open from Phase 3. Keep all commands under `scripts/with-local-env.ps1` and logs under this repository.
