## Prioritized residuals

1. **P1, shipped file fingerprint and size:** `apps/desktop/electron-builder.yml:47-49` copies all of `apps/workflow-ui/dist` as `workflow-frontend` without a filter. The inspected Windows `apps/desktop/release/win-unpacked/resources/workflow-frontend/assets/` contains `ComfyHubPublishDialog-DLT1fsus.js` (90,729 bytes), `comfy-cloud-DgDkMs5k.js`, auth/placeholder chunks, and `.js.map` files. This is packaged code, but the embedded guards above make the account and publish actions unreachable through first-party UI. The observed 346 files matching `Cloud|ComfyHub|Auth|\.map$` total 63,717,448 bytes; most are source maps. `apps/workflow-ui/vite.config.mts:31,769` enables hidden source maps by default. Repro: `Get-ChildItem apps/desktop/release/win-unpacked/resources/workflow-frontend/assets -File | Where-Object { $_.Name -match 'Cloud|ComfyHub|Auth|\.map$' }`. Set release sourcemaps off or filter `.map` from that extra resource, then explicitly exclude proven unused cloud/account chunks without removing compatible local workflow features. Verify the rebuilt unpacked package and installed resources, not only source tree.
2. **P2, latent cloud/account source:** `apps/workflow-ui/src/platform/cloud/`, `src/platform/workspace/`, `src/platform/workflow/sharing/`, `src/config/comfyApi.ts:6-13`, and `src/components/dialog/content/SignInContent.vue` still define inherited cloud URLs, account views, and publishing. `apps/workflow-ui/vite.config.mts:48-49,493-529` aliases or blocks key account assets for the embedded build. Treat source removal as dependency-aware cleanup with import and package gates; a text match alone is not evidence of a runtime call.
3. **P2, dormant desktop key form:** Remove the unreachable `SettingsModal.tsx:532-591` LTX/fal/Gemini key-entry branch after checking the Connections migration path and existing key import confirmation. Retain named provider selectors and required provider links.
4. **P3, compatibility/error strings:** `apps/workflow-ui/src/stores/aboutPanelStore.ts:38-55` contains ComfyUI badges, but `src/components/dialog/content/setting/AboutPanel.vue:6-11` replaces them with a legal attribution paragraph in embedded mode. `src/platform/errorCatalog/runtimeErrorMatcher.ts:116-120` recognizes upstream error prefixes; preserve matching semantics while rewording only app-owned displayed text. `services/workflow/server.py:1538` contains a debug-hang message; it is not part of normal startup.
